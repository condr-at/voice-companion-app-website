# Website — VoiceCompanion Landing Page

**Status: WIP** — minimal context, will be expanded later.

React 19 + Vite + Tailwind CSS 4. Landing page for the voice companion app.

## Commands

```bash
cd website
npm install
npm run dev       # http://localhost:5173
npm run build     # production build → dist/
npm run lint
```

## Structure

```
src/
├── App.jsx, main.jsx, index.css
├── components/   # Hero, Features, FAQ, Pricing, Navigation, etc.
│   └── ui/       # Reusable UI components
├── lib/          # Utilities (typograf)
└── utils/        # Helpers
```
